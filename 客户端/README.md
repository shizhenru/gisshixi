# 空间数据交叉验证工作台

这是一个面向 GIS 综合实习的客户端原型，覆盖：

- 属性、栅格、几何三类异源空间数据的登记与状态展示
- 数据预处理、空间参考统一、范围裁剪和尺度协调流程
- 地图 / 散点图切换、样本点选择、横纵轴变量切换
- GWR 核函数、带宽、带宽策略和距离度量控制
- 全局一致性指标、局部差异分布和结果报告摘要
- 演示数据的报告文本导出

## 运行

无需安装依赖即可运行：

```powershell
python -m http.server 4173
```

打开 `http://127.0.0.1:4173/`。

若使用 Node 环境，也可在安装依赖后运行：

```powershell
npm install
npm run dev
```

当前数据和分析结果为客户端演示数据，后续可将 `src/main.js` 中的 `points` 和 `handleAction()` 接入真实的 Python / GIS 后端。
